Deploy (LIVE sejak 2026-07-20)

Arsitektur hybrid:

BagianDimana
Halaman statis (semua route, termasuk tracker) GitHub Pages (Cloudflare -> gh-pages branch fatihaziz/fatihaziz.github.io) = fatihaziz.com
API + SQLite Fly.io app fatihaziz-web, region sin, volume journal_data di /data (DB_PATH=/data/journal.db, LUNAR_DB_PATH=/data/lunar.db) = https://fatihaziz-web.fly.dev

Halaman statis manggil API lintas origin: build gh-pages di-bake dengan NUXT_PUBLIC_LUNAR_API_BASE=https://fatihaziz-web.fly.dev; CORS untuk /api/lunar/* di server/middleware/lunar-cors.ts (allow fatihaziz.com + localhost:3000). Deploy ulang:

fly deploy --ha=false --remote-only                       # API (dari root repo)
NUXT_PUBLIC_LUNAR_API_BASE=https://fatihaziz-web.fly.dev pnpm build-github
# gh-pages npm kena ENAMETOOLONG di Windows -> push manual .output/public ke branch gh-pages

Notif Telegram / GitHub sync nyala dengan: fly secrets set NUXT_TELEGRAM_BOT_TOKEN=... NUXT_TELEGRAM_CHAT_ID=... NUXT_GITHUB_TOKEN=...

Write-guard lama (NUXT_WRITE_SECRET) sudah digantikan auth phase 1 untuk semua endpoint lunar.

Phase 1-4 (live sejak 2026-07-21)

Auth: dua akun tetap - fatih (role dev, akses penuh) dan product (akun share tim: task, feedback, question, flip bola). Access key dikirim via Fly secrets NUXT_LUNAR_DEV_KEY / NUXT_LUNAR_PRODUCT_KEY (key kosong = akun mati, fail closed). Login: POST /api/lunar/auth/login {username, key} -> Bearer token 30 hari (tabel sessions). Agent LLM/omp: header X-Api-Key: <access key> langsung, tanpa login. Key lokal tersimpan di keyring: keyring get lunar-tracker dev|product. Read (GET /api/lunar/state) tetap publik (keputusan q1 public_read).

SP worklog (phase 2): tabel sp_log(task_id, user, points, spent_on, note). POST /api/lunar/tasks/{id}/worklog (dev only). SP harian + burn 7 hari dihitung dari log, bukan dari task done. Task yang di-done tanpa log otomatis nge-log sisa estimasi. State menambah sprint.estimateOpen, sprint.burn7, tasks[].logged_points.

Roadmap detail (phase 3): tabel subtasks (16 issue trial-critical ter-seed per milestone, sinkron via POST /api/lunar/sync-github) + modal detail per card; kolom features.ball = bola per card (bola utama tetap di settings). Feedback wajib featureId (satu row per error, field link gdocs + attachment); tabel questions terpisah dari feedback, wajib featureId, dev jawab inline (PATCH /api/lunar/questions/{id}).

Upload + Telegram (phase 4): POST /api/lunar/upload (multipart file, png/jpg/webp/gif maks 5MB) ke volume Fly (/data/lunar-uploads), diserve dari GET /api/lunar/uploads/{name}. Telegram notif untuk handover, task baru/done, feedback baru, question baru/dijawab, flip bola card - aktif setelah NUXT_TELEGRAM_BOT_TOKEN + NUXT_TELEGRAM_CHAT_ID di-set (belum di-set).
